C'est quoi un code ?

Un code, c'est une instruction que tu donnes à l'ordinateur pour qu'il exécute quelque chose. L'ordinateur est très obéissant, mais il faut lui parler dans sa langue !

🐱 Commencer avec Scratch

Si tu commences la programmation, commence par Scratch ! C'est un outil gratuit où tu assembles des blocs colorés comme des Lego — pas besoin d'écrire du texte compliqué. Tu peux créer des jeux, des animations et des histoires.

🖥️ Comment accéder à Scratch ?

  • Ouvre un navigateur (Chrome, Firefox…)
  • Tape « Scratch en ligne »
  • Va sur scratch.mit.edu
  • Crée un compte gratuit
  • Ou installe l'application Scratch

📚 Les blocs Scratch par catégorie

  • ■ Mouvement — déplacer ton sprite
  • ■ Apparence — changer l'aspect
  • ■ Son — jouer des sons
  • ■ Événements — démarrer des actions
  • ■ Opérateurs — calculs et logique

🚀 Et après Scratch ?

Quand tu maîtrises Scratch, tu peux apprendre des langages textuels comme Python (idéal pour les débutants), JavaScript (pour les sites web) ou encore C++ (pour les jeux avancés).

L'écran est divisé en 3 zones : les blocs à gauche (tes outils), la zone de code au centre (tu glisses tes blocs ici), et la scène à droite (là où ton jeu s'affiche).

▶ Voir la vidéo : créer une page HTML avec des liens

🏷️ Les balises HTML essentielles

  • <h1> — Titre principal
  • <p> — Paragraphe de texte
  • <a href> — Lien cliquable
  • <img src> — Image
  • <ul> <li> — Liste à puces

🌐 Noms de domaine & URLs

Un nom de domaine (ex: monsite.com) et une URL (ex: http://monsite.com/page/) s'achètent avec l'hébergement web. Des opérateurs comme SFR, Free ou Orange proposent aussi un hébergement.

🛠️ Les outils nécessaires

  • Un éditeur de texte (VS Code, Notepad++)
  • Un navigateur web pour tester
  • Un logiciel FTP : FileZilla ou RealFTP
  • Un hébergement web (OVH, Infomaniak…)

🚀 Et après le HTML ?

Le CSS te permet de styliser ta page (couleurs, polices, mise en page). Le JavaScript ajoute de l'interactivité (boutons, animations). C'est la trinité du web !
